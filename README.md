# OPC Studio - AI创作工坊

> 湖北生而为一科技有限公司

## 📦 这是什么？

一个仿「即梦」的 AI 创作工具，支持：
- 🖼️ **文生图** — 输入文字描述，生成图片
- 🎬 **文生视频** — 输入文字描述，生成视频
- 🎞️ **图生视频** — 上传图片 + 描述，生成视频

调用 OPC Cloud API，一个 Key 通吃所有模型。

---

## 🚀 Windows 使用教程（零基础）

### 第一步：解压

把 `opc-studio.zip` 解压到任意位置，比如桌面。

### 第二步：双击启动

双击文件夹里的 **`start.bat`**，浏览器会自动打开应用。

> 也可以直接双击 **`index.html`**，效果一样。

### 第三步：输入 API Key

第一次打开会弹出欢迎窗口，输入您的 OPC Cloud API Key。

> API Key 获取方式：登录 https://opc.cecctm.com → 个人中心 → 算力管理 → API Key

输入后点「开始创作」，Key 会自动保存，下次打开不用再输。

### 第四步：开始创作

1. 顶部切换 Tab：**文生图 / 文生视频 / 图生视频**
2. 选择模型（自动从服务器拉取）
3. 选择画面比例、时长等参数
4. 输入描述文字
5. 点「生成」按钮
6. 等待生成完成，结果自动显示
7. 鼠标移到结果上可以下载

## 🎨 功能说明

### 文生图
| 参数 | 说明 |
|---|---|
| 描述 | 输入想要的画面描述 |
| 模型 | 自动拉取可用的图片模型 |
| 画面比例 | 1:1 / 9:16 / 16:9 / 3:4 / 4:3 / 2:3 |
| 生成数量 | 1 / 2 / 4 张 |
| 质量 | 标准 / 高清 |
| 风格 | 默认 / 鲜明 / 自然 |

### 文生视频
| 参数 | 说明 |
|---|---|
| 描述 | 输入想要的视频描述 |
| 模型 | 自动拉取可用的视频模型 |
| 画面比例 | 16:9 / 9:16 / 1:1 |
| 时长 | 4 / 7 / 10 / 12 / 15 秒 |
| 帧率 | 24 / 30 / 60 FPS |
| 随机种子 | 可选，用于复现结果 |

### 图生视频
| 参数 | 说明 |
|---|---|
| 上传图片 | 点击或拖拽上传（JPG/PNG/WebP，≤10MB）|
| 描述 | 描述视频内容（可选）|
| 模型 | 自动拉取可用的视频模型 |
| 画面比例 | 16:9 / 9:16 |
| 时长 | 4 / 7 / 10 / 12 / 15 秒 |

## ❓ 常见问题

**Q：打开后提示"未设置API Key"？**
A：第一次使用需要输入 Key，点击 ⚙️ 设置按钮输入即可。

**Q：模型下拉显示"加载失败"？**
A：请检查 API Key 是否正确、网络是否正常。

**Q：视频生成很慢？**
A：视频生成通常需要 1-5 分钟，请耐心等待，不要关闭页面。

**Q：Key 保存在哪里？**
A：保存在浏览器本地（localStorage），不会上传到任何服务器。注意：清除浏览器数据会清除 Key。

**Q：换台电脑能用吗？**
A：可以，把整个文件夹复制过去就行，但需要重新输入 Key。
