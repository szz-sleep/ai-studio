# AI Studio

> 湖北生而为一科技有限公司

AI Studio 是一款桌面端 AI 创作工具，集故事创作、图片生成、视频生成于一体。基于 Electron 构建，支持多平台多模型接入，通过简洁直观的界面让用户无需技术背景即可调用先进的 AI 模型。

## ✨ 核心功能

- 📖 **故事创作** — AI 对话式故事生成，支持上传参考文档（TXT/MD/CSV/JSON）
- 🖼️ **文生图** — 输入文字描述，生成高质量图片
- 🎨 **图生图** — 上传参考图片 + 描述，重新生成图片
- 🎬 **文生视频** — 输入文字描述，生成带音频的视频
- 🎞️ **图生视频** — 上传图片 + 描述，生成动态视频
- 📸 **多图融合** — 支持上传多张参考图进行融合创作
- 🎵 **音色参考** — 视频生成支持参考音频，可参考音色与旋律
- 🖼️ **无水印导出** — 图片和视频生成均默认无水印
- 📜 **历史记录** — 自动保存最近 50 条生成结果，支持单个删除与预览下载
- 🌓 **深色/浅色模式** — 一键切换主题

## 🚀 安装与使用

### 方式一：安装包（推荐）

从 [Releases](https://github.com/szz-sleep/ai-studio/releases) 下载安装包：

- **Windows**: `AI-Studio-Setup-1.0.7.exe` — 安装后从开始菜单启动
- **macOS**: `AI-Studio-1.0.7-x64.dmg` — 拖入 Applications 文件夹

### 方式二：从源码运行

```bash
git clone https://github.com/szz-sleep/ai-studio.git
cd ai-studio
npm install
npm start
```

## 🔧 设置

点击右上角 ⚙️ 设置按钮：

- **平台选择**：火山引擎 / Agnes AI / 自定义
- **API Key**：输入对应平台的 API Key（支持多平台分别保存）
- **API 地址**：自动填充或手动输入
- **数据存储**：所有设置保存在本地（localStorage），不上传任何服务器

## 📜 历史记录

- 自动保存最近 50 条生成结果
- 鼠标悬停缩略图右上角显示 **×** 按钮，点击可**单个删除**（带确认提示）
- 点击缩略图打开预览灯箱
- 图片预览：支持下载，文件名以 `aistudio-image-` 开头
- 视频预览：内置播放器，通过菜单下载，文件名以 `aistudio-video-` 开头

## ❓ 常见问题

**Q：打开后提示"未设置 API Key"？**
A：第一次使用需要点击 ⚙️ 设置按钮，选择平台并输入 API Key。

**Q：模型下拉显示"加载失败"？**
A：请检查 API Key 是否正确、API 地址是否可达、网络是否正常。火山引擎平台会自动回退到内置模型列表。

**Q：视频生成很慢？**
A：视频生成通常需要 1-5 分钟，请耐心等待，不要关闭应用。前台最多会轮询等待 30 分钟，以适配耗时较长的后台任务。

**Q：生成的图片/视频有水印吗？**
A：没有。所有生成的图片和视频默认无水印。

**Q：Key 保存在哪里？安全吗？**
A：保存在本地（localStorage），不会上传到任何服务器。清除应用数据会清除 Key。

**Q：支持哪些操作系统？**
A：Windows（x64）和 macOS（x64）。

## 🛠️ 技术栈

- **Electron** — 跨平台桌面应用框架
- **原生 JavaScript** — 无前端框架依赖
- **electron-builder** — 打包与分发

## 📦 从源码打包

```bash

npm install

# 启动开发
npm start

# 打包 Windows 安装包
npm run build:win

# 打包 macOS DMG
npm run build:mac
```
