# AI Studio - AI创作工坊

> 湖北生而为一科技有限公司

AI Studio 是一款全能型 AI 创作工具，集故事创作、图片生成、视频生成于一体。通过简洁直观的界面，让用户无需技术背景即可轻松调用先进的 AI 模型，实现从文字到图像、从静态到动态的全方位创作体验。

## 📦 核心功能

支持：
- 📖 **故事创作** — AI 对话式故事生成，支持文档参考
- 🖼️ **文生图** — 输入文字描述，生成图片
- 🎨 **图生图** — 上传图片 + 描述，重新生成图片
- 🎬 **文生视频** — 输入文字描述，生成视频
- 🎞️ **图生视频** — 上传图片 + 描述，生成视频

---

## 🚀 使用教程

### 方式一：安装包（推荐）

从 [Releases](https://github.com/szz-sleep/ai-studio/releases) 下载安装包：
- Windows: `AIStudio Setup x.x.x.exe`
- macOS: `AI-Studio-x.x.x-x64.dmg`

### 方式二：浏览器直接打开

1. 解压项目文件夹到任意位置
2. **Windows**: 双击 `start.bat`
3. **macOS**: 双击 `启动.command`

## ❓ 常见问题

**Q：打开后提示"未设置API Key"？**
A：第一次使用需要输入 Key，点击 ⚙️ 设置按钮输入即可。

**Q：模型下拉显示"加载失败"？**
A：请检查 API Key 是否正确、网络是否正常。

**Q：视频生成很慢？**
A：视频生成通常需要 1-5 分钟，请耐心等待，不要关闭页面。

**Q：Key 保存在哪里？**
A：保存在浏览器本地（localStorage），不会上传到任何服务器。注意：清除浏览器数据会清除 Key。
